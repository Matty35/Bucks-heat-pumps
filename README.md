# bucksheatpumps.co.uk

Static lead-generation site for **Bucks Heat Pumps** — MCS-certified air source
heat pump installation for homes in Buckinghamshire, specialising in oil and
LPG boiler replacement. Built around the July 2026 £9,000 Boiler Upgrade
Scheme uplift for oil/LPG homes.

Plain HTML/CSS/JS. No build step, no framework, no dependencies.

## Preview locally

```
python3 -m http.server 8000
# → http://localhost:8000
```

(A server is needed because paths are root-relative; `file://` won't resolve
`/css/styles.css`.)

## Structure

```
/                         Homepage + 3 core service pages + grant hub + about/contact
/heat-pumps-<town>.html   4 location pages (footer-linked only, not in nav)
/guides/                  8-guide content silo (in-content links only, not in nav)
/css/styles.css           Full design system — tokens first, see header comment
/js/main.js               Mobile nav toggle only
sitemap.xml, robots.txt, llms.txt, favicon.svg, 404.html
```

Architecture, silo/linking rules and per-page link maps: **SITEMAP-PLAN.md**.
Competitor research the content strategy is built on: **research/competitor-analysis.md**.

## Quality gates (re-run after content changes)

- **TECHNICAL-CHECKLIST.md** — canonicals, meta, OG, schema, a11y, performance
  (generated by audit script; every claim is machine-checked)
- **DESIGN-QA.md** — responsive audit at 360/768/1280, tap targets, contrast,
  copper-usage rules, link crawl

Two maintenance rules worth knowing:

1. **Critical CSS is duplicated.** Each page inlines a minified critical-CSS
   block in `<head>` for first paint. If you change header/hero/button styles
   in `styles.css`, update the inline block on all pages too (scripted find &
   replace — the blocks are identical byte-for-byte).
2. **Freshness dates.** Guides carry a visible "Last updated: July 2026" line
   plus `dateModified` in their JSON-LD. Bump both when a page materially
   changes. The £9,000 uplift window ends **31 March 2027** — most guide copy
   references it and will need revising then.
